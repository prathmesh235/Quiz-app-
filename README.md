# 🧠 Quiz App

An interactive and responsive Quiz Application. This project allows users to answer multiple-choice questions, view their score, and improve their knowledge through a simple and user-friendly interface.

## 🚀 Live Demo

👉 https://prathmesh235.github.io/Quiz-app-/

## ✨ Features

- 📚 Multiple-choice quiz questions
- ⏱️ Instant answer checking
- 📊 Final score display
- 🔄 Restart quiz option
- 📱 Responsive design
- 🎨 Clean and modern UI

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
